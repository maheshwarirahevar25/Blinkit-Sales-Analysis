# Blinkit-Sales-Analysis


## Objective
Analyzed Blinkit grocery sales data to identify 
product demand trends and support business decisions.

## Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL
- Power BI

## Key Findings
- Identified top performing product categories
- Analyzed outlet wise sales performance
- Found peak demand periods for inventory planning
- Generated category wise insights for business decisions

## Business Recommendations
- Stock high demand products in advance
- Focus on top performing outlets
- Optimize inventory based on demand patterns
